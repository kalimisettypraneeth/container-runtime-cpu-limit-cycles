# Container Runtime CPU Limit Cycles

Research artifact for characterizing quota-induced dynamic behavior in containerized managed runtimes.

## Working paper title
**Characterizing and Mitigating CPU-Quota-Induced Limit Cycles in Containerized Managed Runtimes**

## Research question
Under what combinations of CPU quota, workload burstiness, runtime parallelism, and workload intensity does a containerized managed runtime enter persistent throttling oscillation, and can runtime-aware pacing mitigate it?

## Current status
Research scaffold established. CPU throttling is treated as known prior art; no limit-cycle claim is asserted yet.
